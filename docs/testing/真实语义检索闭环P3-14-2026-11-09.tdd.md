# 真实语义检索闭环 P3-14（2026-11-09）

## 目标

把上一阶段仅有 stub hashing 的政策检索升级为可重复运行的真实 Embedding / Reranker 本地闭环，并确保模型故障、
维度错误或隐式回退不能伪装成“真实语义检索已通过”。

## 实现

- 新增独立 FastEmbed CPU ONNX 服务，提供带 Bearer 鉴权的 OpenAI 兼容 Embedding 与 Reranker 接口；
- 接入 `BAAI/bge-small-zh-v1.5`（512 维）和 `BAAI/bge-reranker-v2-m3-int8`；
- 新增 Embedding / Reranker 严格失败策略、运行计数和健康状态，验收模式禁止哈希及启发式静默回退；
- 隔离启动器增加 `--with-local-models`，使用全新 512 维数据库，避免与旧 1024 维 stub 索引混用；
- 政策基准新增 configured 模式和 8 条中文改写查询，默认 stub CI 契约保持不变；
- 修复 BGE Reranker logits 被误当作 0～1 绝对相关度的问题：召回分数负责无答案门禁，Reranker logits 只负责排序。

## 首轮失败与根因

首轮真实模型基准只有 `9/16` 用例实际保留重排结果，`Recall@5=56.25%`。Embedding 无失败、无回退，问题不在
向量服务，而在检索打分：BGE Cross-Encoder 返回可正可负的未校准 logits，旧代码覆盖原召回分数后再套用
`retrieval_min_score=0.05`，把相关但负 logit 的候选清空。

未降低 Recall 门槛或相关度阈值。修复后保留召回绝对相关度用于拒答门禁，仅使用 logits 决定候选顺序，并增加负
logit 回归测试。
