## 5. 已验证的系统保证

1. 售后回复实际执行 `生成 → 复核 → 修订/补证据/转人工 → 再复核 → 安全落库`。
2. 产品诊断报告在持久化前执行独立反思和结构化修订，最终代码验证不可被模型 `pass` 绕过。
3. `issue_type`、`action_type`、`amount`、`amount_source`、`risk_tier`、`approval_requirement`、`policy_refs` 由服务端快照保护。
4. Reflection/Revision Agent 工具预算为 0；补证据只能走独立受控节点。
5. 反思轮次有上限，预算超限降级为确定性检查或转人工，不形成无限循环。
6. 草稿版本、反思记录、修订记录、停止原因和 generation/reflection/revision 阶段可追踪。
7. 页面只展示业务化摘要和问题清单，不返回 Prompt、模型原始推理或 Chain-of-Thought。
