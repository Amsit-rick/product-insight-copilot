# 正式交付证据只读看板 P3-8 TDD 记录

日期：2026-11-09

## 目标与边界

系统状态页原先只提示“以正式证据为准”，但管理员无法在应用内核对固定的预发布报告和交付检查。本阶段新增只读证据快照接口与管理员看板，应用只读取固定 JSON，不运行门禁、不生成证据、不批准发布，也不修改证据文件。

以下任一情况必须失败关闭，`trusted_production_ready` 保持 `false`：

- 预发布报告或交付检查缺失、无效或 schema 不兼容；
- 证据时间戳缺失、无时区、位于未来或超过 24 小时；
- 运行环境未注入 `APP_RELEASE_SHA`；
- 证据提交与运行版本不一致；
- 六类外部门禁缺项；
- 机器门禁、人工批准或外部门禁没有全部通过。

## 实现结果

- 新增管理员只读接口 `GET /api/v1/delivery-readiness`；
- 系统状态页新增“正式交付证据”卡片，区分本地演示、发布候选和生产验收；
