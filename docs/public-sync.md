2. 从 GitHub 主分支准备干净的发布目录，保留公开说明、脱敏示例和平台专用配置。
3. 只同步经过核对的项目代码、数据库迁移、测试、部署与必要技术文档。真实配置、数据、凭据、运行产物及非项目资料不进入公开提交。

5. 生成普通增量提交并推送，避免覆盖远端更新；推送后复核提交、文件内容与 Actions 状态。
