# 本地运行端口说明

项目有三种本地运行形态，端口不同是正常的。打开页面前先确认你使用的是哪一种，不要把 E2E 临时端口当成开发服务端口。

| 形态 | 默认地址 | 用途 |
|---|---|---|
| 后端 API / 同源静态页面 | `http://127.0.0.1:8000` | `scripts\dev.ps1 run`、零依赖开发、Swagger、健康检查；构建后的前端由 FastAPI 同源托管 |
| 售后演示 / E2E 隔离服务 | `http://127.0.0.1:8010` | 手工按演示脚本启动的独立服务；使用隔离数据库。CI 自动化实际使用 8199，不要手工复用 |
| Vite HMR 开发页面 | `http://127.0.0.1:5180` | `frontend` 目录下的热更新开发；接口由 `VITE_BACKEND` 代理，默认指向 8010 |

客服无指导测试必须使用主持人实际启动的页面地址。推荐先执行：

```cmd
.venv\Scripts\python.exe backend\scripts\prepare_usability_test.py --base-url http://127.0.0.1:8000 --json-out docs\testing\artifacts\usability-prep.json
```

如果按 `演示脚本-3分钟.md` 启动 8010，改为 `--base-url http://127.0.0.1:8010`。以脚本输出的 `test_url` 为准，不要手工猜端口。

E2E 的 8199/9224 等端口由 CI 临时分配，只用于自动化回归，不作为业务方测试地址。
