# UI component attribution

The source components under `src/components/ui/` are adapted from shadcn-vue
(`unovue/shadcn-vue`), new-york-v4 registry, commit `d2684d84b945d0ef8a33793a285cb418d2c2d6e4`.
The original project is a Vue port of shadcn/ui (`shadcn-ui/ui`).
Local adaptations: utility import alias, localized navigation close label,
synchronous controlled input updates, and product theme.
Existing Element Plus business components remain in use.

Upstream: https://github.com/unovue/shadcn-vue
