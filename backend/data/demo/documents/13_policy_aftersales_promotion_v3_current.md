# 售后政策：促销优惠与满减规则 v3.0（现行）

- 生效日期：2026-07-01
- 适用范围：全平台、全店铺
- 状态：现行

## 1. 满减活动

1. 满减按活动页展示的门槛与参与商品计算，跨店满减与店铺满减不叠加。
2. 优惠金额按商品实付金额分摊；发生退款时按分摊后的金额退回，不重复享受优惠。
3. 以下情况满减不会生效：订单未达到门槛、商品不在活动范围、优惠券已过期或已使用、
   活动名额已用完、下单渠道不支持该活动。

## 2. 优惠券

1. 同一订单默认只能使用一张平台券；店铺券与平台券能否叠加，以活动页说明为准。
2. 券未抵扣时先核对五件事：券状态、使用门槛、适用商品、有效期、是否与其他优惠互斥。

## 3. 客服处理口径

1. 先解释活动规则与订单优惠明细，不承诺未经核实的原因。
2. 如确认是系统原因导致"应减未减"，记录订单号、活动页和订单优惠明细截图，转人工核实后
   按补偿流程处理；未核实前不得承诺补发、退差价或退款。
3. 本政策只支持解释与核实，不自动执行退款、补发或赔付。

## 4. 常见问答

- 问：为什么结算页没有减？
  答：先看是否达到门槛、商品是否参加活动、券是否在有效期内；三者都满足仍未抵扣，再转人工核实。
- 问：退款后优惠券会退回吗？
  答：按活动规则与券的使用说明处理；整单退款且券未过期时通常退回，部分退款不重复退券。
