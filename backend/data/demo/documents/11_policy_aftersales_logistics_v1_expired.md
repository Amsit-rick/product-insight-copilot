# 售后政策：物流时效与补偿标准（v1.0 · 已失效）

> ⚠️ 本版本已于 2026-06-30 失效，仅用于政策版本追溯。
> **任何工单处理都不得引用本版本条款** —— 补偿口径已被 v3.0 取代。

| 项目 | 内容 |
|---|---|
| 政策编号 | AS-LOG-001 |
| 版本 | v1.0 |
| 生效时间 | 2025-01-01 至 2026-06-30 |
| 适用范围 | 全平台 |

## 1. 物流停滞认定（旧口径）

1.1 包裹连续 **72 小时**无轨迹更新的，认定为「物流停滞」。
1.2 起算时间自「揽收时间」起算。

## 2. 补偿标准（旧口径，已废止）

2.1 停滞超过 72 小时：补偿 **¥20** 固定金额，单笔补偿不超过 **¥20**。
2.2 补偿以现金形式直接发放至余额。

## 3. 其他

3.1 旧版本不区分会员等级与店铺，统一按固定金额补偿。
3.2 旧版本未规定破损凭证要求，导致大量无凭证赔付，是本次政策修订的主要原因。
