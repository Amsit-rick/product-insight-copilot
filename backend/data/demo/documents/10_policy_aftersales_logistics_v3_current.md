# 售后政策：物流时效与补偿标准（v3.0 · 现行）

| 项目 | 内容 |
|---|---|
| 政策编号 | AS-LOG-003 |
| 版本 | v3.0 |
| 生效时间 | 2026-07-01 起 |
| 适用范围 | 全平台、全店铺、全体会员等级 |
| 归口部门 | 售后服务中心 |

## 1. 物流停滞认定

1.1 包裹在运输途中连续 **48 小时**无轨迹更新的，认定为「物流停滞」。
1.2 停滞时长自**最后一次有效轨迹时间**起算，不含节假日顺延。
1.3 已签收但客户主张未收到的，按「签收异常」处理，须先核实签收凭证（签收人、签收时间、签收地点）。

## 2. 补偿标准

2.1 停滞超过 48 小时：按订单实付金额的 **5%** 补偿，单笔补偿不超过 **¥30**。
2.2 停滞超过 120 小时：单笔补偿不超过 **¥50**，并须升级主管审批。
2.3 补偿以**优惠券或余额**形式发放，不直接退款；已产生实际损失的按第 4 条走退款流程。
2.4 同一订单同一停滞事件只补偿一次，重复申请不予受理。

## 3. 补发与换货

3.1 **少件/漏发**：核实包裹重量与订单标注不一致的，直接补发缺失商品，不涉及赔付。
3.2 **破损**：客户须提供商品本体照片；凭证齐全的直接补发，凭证缺失的先向客户索取。
3.3 **错发**：安排换货，往返运费由平台承担。

## 4. 退款与审批

4.1 退款金额**以支付事实的实付金额为准**，客服与系统均不得自行调整。
4.2 退款一律需要**主管审批**：审批人须核对订单事实、政策依据与金额一致性。
4.3 单笔退款金额达到 **¥5000** 以上的，转风控专案处理，禁止自动执行。

## 5. 时效要求

5.1 首次响应不超过 6 分钟（工作时间）。
5.2 物流停滞类工单在联系承运商后 **24 小时**内须回访客户；超时未闭环的升级主管。
