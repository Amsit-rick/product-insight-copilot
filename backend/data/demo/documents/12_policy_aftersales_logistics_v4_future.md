# 售后政策：物流时效与补偿标准（v4.0 · 未生效）

> ⏳ 本版本自 **2027-01-01** 起生效，当前**不得作为处理依据**。
> 上线前请勿在工单处理中引用：新旧口径的补偿上限不同，提前引用会造成赔付口径不一致。

| 项目 | 内容 |
|---|---|
| 政策编号 | AS-LOG-004 |
| 版本 | v4.0 |
| 生效时间 | 2027-01-01 起 |
| 适用范围 | 全平台；**仅自营店铺**（POP 店铺不适用） |

## 1. 物流停滞认定（新口径，待生效）

1.1 停滞认定时长由 48 小时收紧至 **36 小时**。
1.2 引入「预计送达时间」自动比对，超时未达即计入停滞。

## 2. 补偿标准（新口径，待生效）

2.1 停滞超过 36 小时：按订单实付金额 **8%** 补偿，单笔不超过 **¥50**。
2.2 停滞超过 120 小时：单笔不超过 **¥80**。
2.3 补偿统一以优惠券发放，有效期 90 天。

## 3. 与 v3.0 的差异

| 项 | v3.0（现行） | v4.0（待生效） |
|---|---|---|
| 停滞门槛 | 48 小时 | 36 小时 |
| 补偿比例 | 5% | 8% |
| 单笔上限 | ¥30 / ¥50 | ¥50 / ¥80 |
| 适用范围 | 全店铺 | 仅自营店铺 |
